# 1. WHAT is a Function?

A function is a block of code that does a specific task.

## 👉 Simple idea:
“Write once, use many times”

## Function with Parameters
## WHAT?

Send data into function.

## Function with Return Value
## WHAT?

Function gives back a result.

## Function with Return Value
## WHAT?

Function gives back a result.

int add(int a, int b) {
  return a + b;
}

### Use:
int result = add(5, 3);
print(result);

# Types of Functions
## 1. No parameter, no return

void showMessage() {
  print("Welcome");
}


## 2. Parameter, no return
void printName(String name) {
  print(name);
}

## 3. Parameter + return
int multiply(int a, int b) {
  return a * b;
}
