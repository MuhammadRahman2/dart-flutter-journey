# 1. WHAT are Collections?

Collections store multiple values in one variable.

Instead of:

String name1 = "Ali";
String name2 = "Ahmed";

You use:

List names = ["Ali", "Ahmed"];


## 2. LIST (Most Important)
✅ WHAT?

Stores ordered data (index-based)

List<String> names = ["Ali", "Ahmed", "Rahman"];

## 3.SET
✅ WHAT?

Collection of unique values


## 4. MAP (Very Important)
✅ WHAT?

Stores data in key-value pair
